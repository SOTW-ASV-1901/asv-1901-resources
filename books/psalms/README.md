# Servants of the Way | ASV1901 Psalms

An additive resource for 150 chapters and 2461 verses. Verse spans preserve 363 translator-supplied italic segments verified against the comparison witness. Original historical PDF pages 580–670 are preserved unmodified in compact volumes.

Psalms headings, traditional superscriptions, book divisions, and Psalm 119 alphabet stanzas are retained as separately typed chapter headings, not inserted into Scripture verse text. USFM musical notation brackets are compared with printed [Selah / [Higgaion marks.

Installation: upload `books/psalms/` and `data/asv1901/psalms/` plus `data/asv1901/catalog-psalms.json` to repository root. Local reader: `books/psalms/site/index.html`. No shared catalog or homepage.

This is chapter/page-level inspection, not every-character proofing. Source digital witness independence is not proven. No unverified lexical alignments have been imported.
