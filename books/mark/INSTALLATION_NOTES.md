# Mark | GitHub installation

Unzip the standalone release, then upload the **root `books` and `data` folders** through GitHub Add file → Upload files, preserving root paths. Only `books/mark/`, `data/asv1901/mark/`, and `data/asv1901/catalog-mark.json` are added. Do not overwrite Matthew or any Old Testament files. Validate the published reader separately after upload because a local HTTP read test is not a hosted-browser verification. This is a manually uploaded source foundation, not a change to CGBC's locked media-player deployment.
