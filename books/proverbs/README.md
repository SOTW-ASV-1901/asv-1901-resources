# Proverbs | American Standard Version (1901)

**Servants of the Way | Book 20 | additive, standalone foundation**

This edition provides **31 chapters, 915 verse positions**, 209 translator-supplied italic spans and 31 original 1901 historical scanned pages. Original PDF pages **671–701** correspond to printed Old Testament pages **629–659**. The facsimiles preserve original full printed pages, including headings, margins, punctuation, and historic editorial notes. Each verse links to the actual original page (or two consecutive physical pages if a verse spans a page break).

Text source precedence: original 1901 printing for supported disagreements, primary English-only USX witness for verse text and paragraph/italic span structure, comparison USFM witness for differences. Source files are byte-preserved, and each departure from the primary source is documented in `build-inputs/source-differences-resolved.json`.

The two source differences concern **Proverbs 14:10** (`inter-meddle` versus `intermeddle`) and **Proverbs 27:1** (`tomorrow` versus `to-morrow`). The print at Proverbs 14:10 splits `inter-`/`meddle` at a physical line break, which is not sufficient alone to establish lexical hyphenation. Retain the primary witness's `inter-meddle` and preserve the uncertainty. The printing of 27:1 splits `to-`/`morrow`; Proverbs 3:28 prints unbroken `to-morrow`, supporting the comparison reading, which is selected in derived Scripture text. Both source witnesses remain unchanged.

**Verification scope.** All chapter and verse IDs from both source witnesses, 31 physical page boundaries, every verse-to-page mapping, all 209 supplied spans against the primary witness, and source archive/file SHA-256 hashes are machine-checked. PDF embedded image streams and page placements are checked against the parent scanned file. Six representative page renders are compared pixel-for-pixel at equal resolution. This is **not** a claim of full character-by-character collation against all 31 printed pages, digital source independence, or tested public hosted browser behavior. The USFM's preexisting English-to-Strong's tags are deliberately not imported as verified original-language alignments.

The original whole 135 MB source PDF is not included, only the relevant original unedited pages. Parent source checksum and exact origin are in `SOURCE_INVENTORY.json`.
