# Installation | Proverbs

Unzip the standalone archive. At the GitHub repository root, upload the two top-level folders **`books`** and **`data`** using **Add file → Upload files**. Preserve all relative paths.

New paths only:

```
books/proverbs/
data/asv1901/proverbs/
data/asv1901/catalog-proverbs.json
```

No existing book, shared index, global catalog, history directory, or main-site file is replaced. This book-specific package is comfortably below the 99-file upload limit. After manual installation, inspect the uploaded file tree and compare hashes against `books/proverbs/RELEASE_MANIFEST.json`. GitHub Pages hosting requires a compatible site base/path; hosted browser interactions have not been validated here.
