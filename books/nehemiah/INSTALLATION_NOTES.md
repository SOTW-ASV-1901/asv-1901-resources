# Installation | Nehemiah

Upload the directory trees `books/nehemiah/` and `data/asv1901/nehemiah/` plus `data/asv1901/catalog-nehemiah.json` to the repository root. These paths are additive; no shared files or other books are modified.

Local verification: `python books/nehemiah/scripts/validate_release.py .`

Reader: `books/nehemiah/site/index.html`
