# 2 Corinthians upload-scope audit

This release contains only the new `books/second-corinthians/` tree, `data/asv1901/second-corinthians/` tree and `data/asv1901/catalog-second-corinthians.json`. No other Bible book, shared catalog, player UI or historic source file is overwritten. The publisher-specific attribution UI is deliberately deferred to a shared metadata enhancement rather than inconsistent book-by-book patches.
