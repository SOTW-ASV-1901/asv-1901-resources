# Installation | Ezra

Upload the directory trees `books/ezra/` and `data/asv1901/ezra/` plus `data/asv1901/catalog-ezra.json` to the repository root. These paths are additive; no shared files or other books are modified.

Local verification: `python books/ezra/scripts/validate_release.py .`

Reader: `books/ezra/site/index.html`
