# 1 Corinthians | American Standard Version (1901)

**Servants of the Way | Book 46 | additive, source-locked Bible edition foundation**

Includes **16 chapters**, all **437** 1901 main-text verse positions, page-linked original 1901 historical facsimiles and a book-local HTML Scripture evaluation reader with chapter/verse selection and **Compare original**. The original scan has PDF pages 1167–1181, printed NT pages 173–187. All original pages and historical footnotes remain in the facsimile.

Source precedence: the exact 1901 printed Thomas Nelson standard American edition controls verified source conflicts; the pinned English-only USX supplies the original digital base and structured translator-supplied italic spans; the pinned comparison USFM provides a cross-witness check. Both digital source files are retained byte-for-byte. The 1901 whole-Bible 135 MB scan remains outside this add-only release; only original 1 Corinthians pages are included.

Neither witness is accepted as independent of the other without provenance proof. The comparison USFM's word-to-Strong's tags are not imported. Manuscript notes are distinct from main-text verses; no unsupported lexical mapping is introduced. See the original scan, all preserved original notes, `SOURCE_INVENTORY.json`, `textual-apparatus.json` and `build-inputs/source-differences-resolved.json`.

**Independent validation scope:** exact source SHA-256 matches, all verses/chapters/italics, page-index coverage and physical transitions, preserved original page image streams and placement transforms, representative rendered pixel equality, metadata schema, local HTTP resource checks, and byte-identical rebuild. This does **not** claim exhaustive character-for-character print proofreading, verified digital witness independence, or hosted-browser evaluation.
