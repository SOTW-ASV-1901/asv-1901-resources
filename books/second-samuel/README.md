# 2 Samuel | ASV 1901 Scripture Foundation

This single-book release supplies **24 chapters / 695 verses**, translator-supplied italics, historically indexed 1901 facsimile pages, source and rights records, automated validators and an optional book inspection reader.

- Distribution data: `data/asv1901/second-samuel/`
- Provenance and validation: `books/second-samuel/`
- Optional local inspection reader: `books/second-samuel/site/index.html`
- Local validation: `python3 books/second-samuel/scripts/validate_release.py .`

The central Servants of the Way organization, not this independent ASV data foundation, will host the official integrated Bible reader. The bundled inspection page is optional and does not establish a master ASV website.
