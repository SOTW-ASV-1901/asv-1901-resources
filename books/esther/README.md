# Servants of the Way | ASV 1901 | Esther

This is an additive **single-book** edition resource. It includes 10 chapters and 167 verses, with 25 translator-supplied italic spans encoded in text. Both digital witnesses agree on verse wording and supplied-span boundaries.

The full-page original 1901 facsimile spans source PDF pages 532–541, including 8 Scripture pages and 2 associated historical non-Scripture pages. All are retained in compact PDF volumes. The page index stores physically verified verse continuations separate from running headers.

Open `books/esther/site/index.html` through GitHub Pages or a local HTTP server rooted at repository root. Compare a selected verse against its original scanned page.

The original complete scanned Bible is source-hash referenced but intentionally not bundled. The two digital witness subfiles are preserved unchanged. The USFM witness includes unverified Strong’s annotations that have not been imported as Hebrew word alignments.

## Installation

Merge this ZIP's `books/` and `data/` directories into the target repository root. Do not delete or overwrite existing installed books. No shared master catalog or site is included.

## Validation limitations

Chapter coverage, page boundaries, witness wording and supplied spans were checked. This is **not exhaustive character-by-character 1901 print proofreading**. Hosted browser interaction was not tested.
