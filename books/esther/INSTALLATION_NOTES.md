# Installation | Esther

Upload the directory trees `books/esther/` and `data/asv1901/esther/` plus `data/asv1901/catalog-esther.json` to the repository root. These paths are additive; no shared files or other books are modified.

Local verification: `python books/esther/scripts/validate_release.py .`
