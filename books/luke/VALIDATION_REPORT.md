# Luke | ASV 1901 release validation

Luke's 24 chapters and 1,149 main-text verse positions are crosschecked between the digital sources and the original 1901 edition. Verse numbers Luke 17:36 and 23:17 are noted in the original apparatus, not in main running text; they are included only as omitted-verse metadata. The paired digital witnesses differ in 26 typography-only instances, and 209 supplied-word USX spans correspond to 208 USFM runs, with one innocuous segmentation difference at Luke 6:16. Both original digital source files are preserved exactly. The 1901 source edition controls any historical transcription choices.

The source hash, page index, physical facsimile contents, JSON schemas, local resource loading, reader JavaScript, and reproducing the build are independently audited. The historic original includes manuscript notes at Luke 22:43–44, 23:34, 24:12, 24:40, 24:51 and 24:52. Those notices are distinguished from the running text.

This project release **does not** certify complete character-by-character proofreading against the historical print, independent production of the digital witnesses, independently proven lexical alignment, or hosted GitHub browser testing. See the structured validation and independent audit for definitive pass/fail results.
