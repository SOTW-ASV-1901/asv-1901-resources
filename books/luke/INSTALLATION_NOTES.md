# Luke | manual GitHub installation

Unzip this release and upload its two root folders (`books` and `data`) using **Add file → Upload files** at `SOTW-ASV-1901/asv-1901-resources` repository root. Only three paths are added: `books/luke/`, `data/asv1901/luke/`, and `data/asv1901/catalog-luke.json`. Do not overwrite Mark, Matthew, any Old Testament books, or any shared catalog. Verify hosted GitHub browser behavior after installation; this local release check cannot certify GitHub Pages deployment. The original 135 MB whole-scanned Bible PDF remains outside this small standalone ZIP.
