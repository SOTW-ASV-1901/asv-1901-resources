# Installation | Obadiah

Extract ZIP, drag its root-level `books` and `data` directories into GitHub `Add file → Upload files` from the repository root. Do not upload the ZIP itself. The upload adds only `books/obadiah/`, `data/asv1901/obadiah/`, `data/asv1901/catalog-obadiah.json`. All files are additive and no other book is changed.
