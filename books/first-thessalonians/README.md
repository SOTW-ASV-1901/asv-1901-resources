# 1 Thessalonians | American Standard Version (1901)

**Servants of the Way | Book 52 | additive, source-locked Bible foundation**

The book includes **5 chapters and 89 main-text verses**, all original 1901 Bible pages and a book-specific evaluation reader with **Compare original** navigation. Historical PDF pages **1212–1215** correspond to printed New Testament pages **218–221**. Verses extending across pages link to each original physical page. Original typography and marginal annotations remain visible in unaltered source-page facsimiles.

Text precedence: verified original 1901 print controls documented discrepancies; primary English-only USX supplies main text, paragraphs and translator-supplied italics; comparison USFM is an additional digital witness whose independent provenance is not established. Source witnesses have two differences: one typographic ligature in 2:14 corrected to the printed “Judæa”, and a hyphenation ambiguity in 5:14 (primary “faint-hearted”, comparison “fainthearted”) whose printed line break does not resolve lexical spelling. Print-backed editorial decisions and unresolved uncertainties appear in `build-inputs/source-differences-resolved.json`. The original witness files remain byte-for-byte unchanged.

The complete parent ~135 MB Bible scan is not included. Only original 1 Thessalonians pages are bundled, with original-page identities, SHA-256 source fingerprint and facsimile integrity checks. No unverified English-to-Strong's alignments are imported.

**Quality boundaries:** Chapter/verse IDs, both digital witnesses, supplied words, source hashes, original image-stream and placement identity, selected rendered scans, physical page boundaries, local reader syntax/resources and deterministic rebuilds are audited. No claim of exhaustive character-by-character print collation or hosted GitHub Pages browser testing.
