# Jeremiah | Independent verification and limitations

**52 chapters, 1,364 verses, 144 translator-supplied italic spans.** Both source witnesses have been compared verse by verse; they differ only in the capitalization of *Is* in Jeremiah 8:19. Original 1901 printed PDF source page 781 reads `Is`, so the primary source is retained. Both original witness files are preserved unchanged, and their independence is unestablished.

The original 1901 Bible occupies **61 original PDF pages 772–832**, corresponding to printed pages **730–790**. All source page openings/closings were examined and **55 two-page verse continuations** indexed. Original embedded image stream bytes and placements were checked on all 61 pages; rendered pixels matched on all 61 at 0.8× scaling. All facsimiles preserve whole pages and are split into three compact volumes.

Independent audit validates all chapter JSON and page index schemas, supplied span agreement with independently parsed USFM markers, SHA-256 source/manifest hashes, complete deterministic data and facsimile rebuild, local HTTP resource availability, reader JavaScript syntax, ZIP CRC integrity and no conflicts with existing book paths. The book ZIP contains fewer than 99 files.

**Limits:** No exhaustive character-by-character collation of 1,364 verses against the physical print; no hosted browser interaction test; no unverified Strong's number-to-word assignments. The original 135 MB source PDF is checksum-pinned and not repackaged as a whole.
