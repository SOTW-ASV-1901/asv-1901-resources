## Source, rights and fidelity

The print edition governs historical fidelity. The unchanged English-only USX file controls the main text, paragraph indicators, and 135 translator-supplied italic spans. The unchanged USFM comparison confirms all main-text verse positions apart from traditional verse 5:4 (which is only an original print note), and agrees on all italicized supplied wording. The 16 paired-source main-text differences are typographic (chiefly historical ligatures and print small capitals) and documented individually. The original print's small-capital inscription at John 19:19 is projected in uppercase while both source files remain untouched.

John 7:53–8:11 remains visible in the 1901 main text exactly as bracketed, but the original historical note is visible separately. Additional notes of the original edition remain in the unaltered USX witness (271 notes) and in the original page facsimiles. This is edition documentation, not an independent modern textual-critical judgment.

Validation covers source hashes, chapter structure, original scanned page identity, page-to-verse navigation, supplied-word italics, local reader resources, reproducibility, and archive integrity. It does **not** constitute full character-by-character proofreading of all 28 printed Scripture pages, independent witness origin proof, or a hosted GitHub Pages browser test. Third-party English-to-Strong's alignments were intentionally not imported as trustworthy lexical mappings.
