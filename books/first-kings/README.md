# 1 Kings | Servants of the Way ASV 1901 Foundation

This standalone book release provides **22 chapters / 816 verses**, translator-supplied italics as typed Scripture data, original-print facsimile page mapping and PDFs, source records, validation tools, and an optional book inspection reader.

- Scripture and facsimiles: `data/asv1901/first-kings/`
- Sources, tests, and evidence: `books/first-kings/`
- Reader (inspection only): `books/first-kings/site/index.html`
- Validation: `python3 books/first-kings/scripts/validate_release.py .`

The intended official integrated Bible reader will be maintained at the central Servants of the Way Foundation, not in this independent ASV resource organization.
