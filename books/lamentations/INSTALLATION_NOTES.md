# Installation | Lamentations

This additive release adds only `books/lamentations/`, `data/asv1901/lamentations/`, and `data/asv1901/catalog-lamentations.json` at the repository root. Earlier books, site, and shared catalog stay untouched.

Extract the ZIP, then drag both top-level `books` and `data` folders into GitHub Add file → Upload files (dragging folders, not selecting with file picker). Local check: `python books/lamentations/scripts/validate_release.py .`. The original full scan is hash-pinned but not included.
