# Acts | American Standard Version (1901)

**Servants of the Way | Book 44 | additive, standalone, source-locked foundation**

Original ASV1901 Acts: **28 chapters, 1003 main-text verses**, with 1007 traditional numbered positions. The traditional positions **ACT.8.37, ACT.15.34, ACT.24.7, ACT.28.29** appear in the original printed textual apparatus rather than as main-text verses, and are not fabricated from the comparison witness. 6 historical original maps and 5 blank original reverse leaves are preserved in physical PDF sequence. 

The 1901 source PDF pages 1104–1150 correspond to numbered New Testament Scripture pages 121–156. The exact original scanned page images, original marginal notes, page typography and map placements are retained in the facsimile PDFs. Original page and verse boundaries are included in `data/asv1901/acts/page-index.json`. A verse can cross a physical page boundary; the reader includes a **Next verse page** button that jumps over a historical map/interleaf when necessary.

The original 1901 printing is the controlling source for documented disagreements. The source-locked English-only USX provides the base edition text, paragraph indicators, and translator-supplied italics. The alternate USFM is used for independent text comparison but its provenance independence is not established; its unverified word-to-Strong's links are not imported. Exact original digital files are preserved unchanged. Print-backed corrections to derived text and all source divergences are documented under `build-inputs/source-differences-resolved.json`.

The original parent 135 MB Bible PDF is checksum-identified but not bundled. This package includes original pages only. No existing books, GitHub production pages or shared indexes are changed.

Validation includes source SHA-256, verse positions, page boundaries, unmodified source witnesses, facsimile embedded-image stream and transform identity, selected pixel-render comparisons, schemas, local reader HTTP tests, and byte-for-byte reproducibility. This is **not** full character-by-character collating of every printed page, independent confirmation of digital witness origin, or a claim of hosted-browser testing. See release manifest, validation and independent audit.
