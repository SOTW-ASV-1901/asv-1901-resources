# Philippians | American Standard Version (1901)

**Servants of the Way | Book 50 | additive, source-locked edition foundation**

This book includes **4 chapters, 104 main-text verses**, all original 1901 scanned book pages and a book-specific evaluation reader with **Compare original** chapter/verse-to-page navigation. Historical source PDF pages **1204–1207** correspond to printed New Testament pages **210–213**. The original printed pages, original historical spelling, footnotes, and page breaks remain preserved. Verses continuing across a page boundary link to both physical pages.

The primary English-only USX provides the initial text, paragraphs, and supplied-word italics. The comparison USFM is a second digital source, but its provenance independence is **not established**. The original 1901 print controls supported discrepancies. Two typography-only USX/USFM differences in Philippians (prætorian in 1:13; Cæsar’s in 4:22) were reconciled to the historical 1901 printed text; original source files stay unchanged. The actual print-backed changes are documented in `build-inputs/source-differences-resolved.json`. The original 1901 marginal apparatus remains physically visible in the facsimiles and structurally present in unchanged USX source; one specific note is highlighted in the reader and in `textual-apparatus.json`.

Both source witnesses are preserved byte-for-byte and their original hashes are recorded in `SOURCE_INVENTORY.json`. The 135 MB parent Bible scan is not bundled, only exact unedited historic pages. No unsupported Strong's word alignments are imported from existing markup.

**Quality boundary:** IDs, chapter/verse structure, supplied italics, source fingerprints, scan image-stream identity and transformations, selected page renders, printed-page boundaries and verse-to-page coverage, local HTML resources, and reproducible source rebuilding are independently tested. This is not full character-by-character collation of the main text against the 1901 print or a claim of hosted-browser testing.
