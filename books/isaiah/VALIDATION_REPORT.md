# Isaiah | Independent validation and limitations

**ASV 1901 Isaiah: 66 chapters, 1,292 verses, 209 separate translator-supplied italic spans.** Two digital witnesses agree on the verse text and supplied spans. Independence of the two witnesses is not proven. Both source files are preserved byte-unchanged.

Original historical print occupies **55 source PDF pages 717–771** (printed pages **675–729**). All pages are retained in three compact full-page PDF volumes. The verse index covers all 1,292 verses, with 47 verse continuations across adjacent printed pages. Physical page openings, closings and column transitions were inspected against original print; this is **not an exhaustive letter-by-letter collation**.

The independent audit verifies embedded image hashes and position/dimensions for all 55 copied pages, 1× rendered pixel equality for all 55 pages, chapter and page-index schemas, 209 supplied spans against independently parsed comparison markers, deterministic byte-identical rebuilding of JSON and facsimile PDFs, browser reader JavaScript syntax, local HTTP retrieval of the packaged resources, SHA-256 manifest and ZIP CRC/integrity, and zero collisions with the previous release paths or the checked GitHub `main` baseline.

The release is source-locked, reproducible, additive, and contains fewer than 99 files. Original 135-MB source PDF stays outside the package; its checksum and page range are pinned. No bulk Strong's assignments or unverified word-to-original-language mapping is claimed. Hosted GitHub Pages browser interaction has not been tested.
