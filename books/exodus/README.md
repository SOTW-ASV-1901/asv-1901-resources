# Servants of the Way | ASV 1901 Exodus Foundation Release

**Book 2 of the planned ASV 1901 Foundation.** All 40 Exodus chapters and 1,213 verses, with structured supplied-word italics and a locally hosted historical Compare viewer. Source PDF pages 77-122 from the owner-provided 1901 original are retained as 46 untouched complete physical pages, including the period map and blank verso.

This package uses the same reader/file/index contract as the previously produced Genesis package. Install into the intended independent ASV Foundation repository without replacing or altering existing Genesis files. This archive is book-scoped and is intended for incremental installation into the separately administered ASV Foundation repository.

- `books/exodus/index.html` directs to the Exodus reader in `books/exodus/site/index.html`.
- `data/asv1901/exodus/chapters/*.json` is the 40-chapter Scripture projection.
- `data/asv1901/exodus/page-index.json` maps Scripture verses to original printed pages and facsimile PDF volumes.
- `data/asv1901/catalog-exodus.json` records its place after Genesis for future multi-book readers.
- `books/exodus/build-inputs/` records page evidence, comparison differences and scoped chapter review.
- `books/exodus/scripts/` contains reproducible build and validation code.
- `VALIDATION_REPORT.md` explains the scope and test results.

**Boundary:** The digital source comparison and chapter-by-chapter historical inspection are not a character-by-character proof of the original printing. Original maps remain historical evidence, not factual endorsement of their geography. The ASV italics are not direct Hebrew/Greek word alignment. No production repository was edited.
