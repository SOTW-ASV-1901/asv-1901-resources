# Installation | Zephaniah

Extract ZIP, drag its root-level `books` and `data` directories into GitHub `Add file → Upload files` from the repository root. Do not upload the ZIP itself. The upload adds only `books/zephaniah/`, `data/asv1901/zephaniah/`, `data/asv1901/catalog-zephaniah.json`. All files are additive and no other book is changed.
