# Installation | Song of Solomon

This additive release adds only `books/song-of-solomon/`, `data/asv1901/song-of-solomon/`, and `data/asv1901/catalog-song-of-solomon.json` at the repository root. Earlier books and the shared catalog stay untouched.

Extract and drag the `books` and `data` folders together into GitHub Add File → Upload Files. Local check: `python books/song-of-solomon/scripts/validate_release.py .`. Original full print is checksum-pinned but not included.
