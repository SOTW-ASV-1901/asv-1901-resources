# Installation | Ezekiel

Add only `books/ezekiel/`, `data/asv1901/ezekiel/`, and `data/asv1901/catalog-ezekiel.json` at the repository root. Extract the ZIP and drag both `books` and `data` top-level directories into GitHub’s Upload files area. No earlier books, shared site or global catalogs are replaced. Validate with `python books/ezekiel/scripts/validate_release.py .`.
